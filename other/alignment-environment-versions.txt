Reproduce (only when rebuilding the environment; current .venv-align is ready):
  python3 -m venv .venv-align
  .venv-align/bin/python -m pip install -r requirements-align.txt
  .venv-align/bin/python -m pip install --no-deps whisperx==3.3.4

WhisperX is deliberately installed without optional ASR/diarization dependencies.
The final batch script uses WhisperX to load the English model, then
 torchaudio.functional.forced_align + merge_tokens for character timestamps.
This avoids the legacy WhisperX 3.3.4 backtracking boundary issue.
Only alignment functionality is supported in this dedicated environment.
The requirements file pins the complete installed Python dependency set.
On this server the Tsinghua PyPI mirror is reachable; large torch/cudnn wheels
were fetched from official files.pythonhosted.org through the user's existing
loopback proxy and verified against PyPI SHA256 metadata before installation.
No system Python packages or proxy configuration were changed.
